左被殻出血後に生じたブラキシズムに対するA型ボツリヌス毒素注射の症例報告

Case Report: Botulinum Toxin Type A Injection for Bruxism Following Left Basal Ganglia Hemorrhage.

脳卒中後に発症したブラキシズムに対し、STABによる多面的評価のもとA型ボツリヌス毒素を咬筋に注射したところ、症状改善が6か月間持続したとする単一症例報告。

背景・目的

脳卒中後のブラキシズムはあまり知られていない合併症であり、口腔機能障害や顔面口腔部の疼痛を引き起こし、リハビリテーションの経過に悪影響を及ぼす可能性があるとされています。A型ボツリヌス毒素(BoNT-A)はブラキシズムへの使用が報告されていますが、脳卒中後の患者への適用に関する報告は少ないとされています。本報告では、脳出血後に発症したブラキシズムの評価と治療を、Standardized Tool for the Assessment of Bruxism(STAB)という構造化された多面的評価枠組みを用いて記述しています。

対象

大規模な左半球脳内出血に対して減圧開頭術と血腫除去術を受けた40歳男性1例。入院後約3か月で、両側咬筋肥大と著明な圧痛、顎関節痛、右口角からの流涎を認め、ブラキシズムの既往はありませんでした。

方法

STABに基づき、主観的評価(介護者による夜間の歯ぎしりの報告)、臨床的評価(両側咬筋肥大、触診時圧痛、歯の摩耗)、機器による評価(表面筋電図による安静時・咬みしめ時の咬筋活動の確認)という3側面から評価を行いました。咬合スプリント療法と温罨法の併用では症状が改善しなかったため、筋電図ガイド下に両側咬筋へBoNT-Aを注射しました(片側50単位、各側3部位に分けて投与)。

結果

注射48時間後には筋緊張と圧痛が著明に軽減し、6か月の追跡時点でも臨床的改善が持続していたと報告されています。

臨床的示唆

本症例では、BoNT-A注射が脳卒中後ブラキシズムの症状軽減と時間的に関連していたことが示されました。STABは、ブラキシズムを多面的に評価するための構造化された枠組みとして活用できる可能性があります。ただし、著者ら自身も述べているように、これは記述的な単一症例の報告であり、一般化には限界があるとされています。

限界

  • 単一症例報告であり、対照群が存在しないため、症状改善がBoNT-A注射によるものか自然経過や他の要因によるものかを区別できません。
  • 効果や安全性を確立するためには対照を伴う研究が必要であると著者らも述べています。
