がんリハビリテーション後の復職における社会経済的格差:ドイツ年金保険データを用いた分析

Socioeconomic differences in return to work after oncological rehabilitation: An analysis using data from German Pension Insurance.

ドイツの公的年金保険データを用いた分析で、低所得層はがんリハビリテーション後の復職率が低いという社会経済的格差が示されました。

背景・目的

がん治療後に就労者が復職できない場合、収入の喪失や社会的つながりの減少といった不利益が生じうるとされています。本研究は、社会経済的に不利な立場にある人々が、がんリハビリテーション後に復職しにくい傾向にあるかを検討することを目的としています。

対象

ドイツ年金保険の『保険加入歴における完了したリハビリテーション』に関する学術利用ファイル(2014年~2021年)に含まれる、がんリハビリテーションを終えた人々のデータが用いられました。

方法

社会経済的特性として、学歴、職業スキルレベル、リハビリテーション前の収入が検討されました。復職成功は、リハビリテーション終了24か月後に週労働時間の50%以上就労していることと定義されました。性別で層別化したCox比例ハザード回帰モデルが用いられ、年齢や居住地域などの変数で調整が行われました。

結果

リハビリテーション2年後の就労率は67.2%(女性70.0%、男性63.4%)でした。特に低所得層は、年齢や居住地域などの他変数を調整した後も、高所得層と比較して復職の可能性が低いことが示されました。

臨床的示唆

がんリハビリテーション後の復職支援において、低所得層など社会経済的に不利な立場にある人々への配慮や追加的支援の必要性を示唆する結果です。ただし、ドイツの公的年金保険制度に基づくデータであり、医療・社会保障制度が異なる日本の臨床現場へそのまま適用することには注意が必要です。

限界

  • 観察研究のため、社会経済的要因と復職率の関連は因果関係を示すものではありません。
  • ドイツの公的年金保険制度下のデータであり、制度・社会背景が異なる国への一般化には限界があります。
  • 復職の定義が週労働時間の50%以上という基準に基づくため、それ以外の就労形態や復職の質的側面は反映されていません。
