適応的な計算論的表現型分析による軽度認知障害と健常加齢における記憶機能障害の信頼性の高い検出と継続的モニタリング

Reliable detection and continuous monitoring of memory dysfunction in mild cognitive impairment and healthy aging through adaptive computational phenotyping.

軽度認知障害患者と健常高齢者計51名が週1回・最長1年間の遠隔記憶課題を行い、記憶の固定・忘却モデルに基づく個別スコア(SGMA)が信頼性と診断精度を示した研究です。

背景・目的

加齢に伴う記憶障害の増加を受け、その早期検出と継続的モニタリングの必要性が高まっています。しかし従来の評価法は対面実施が前提で、頻回な反復実施が難しいという課題がありました。本研究は、オンライン評価プラットフォームと計算論的モデルを組み合わせることで、遠隔・無監督下での記憶機能の反復観察が可能かを検討しています。

対象

健忘型軽度認知障害患者24名と、年齢・教育歴をマッチさせた健常高齢対照者27名の計51名。いずれも詳細な評価を受けた対象者です。

方法

対象者は、8分間の記憶課題からなるオンライン評価を週1回、最長1年間、遠隔かつ無監督で継続的に実施しました。得られた週次のテストデータを、記憶の固定と忘却に関する形式的な計算モデルに当てはめ、個人ごとの記憶機能指標であるSeattle-Groningen Memory Assessment(SGMA)スコアを算出しました。

結果

SGMAスコアは評価間で平均相関r=0.70という信頼性を示しました。また使用する課題素材が異なっても安定しており、練習効果による影響も1回の評価あたり平均0.2%の上昇とわずかでした。さらにSGMAスコアは軽度認知障害を最大87%の精度で検出できることが示されました。

臨床的示唆

モデルに基づく適応的な評価を用いることで、記憶機能の高頻度・遠隔での検出と、経時的な変化を追う拡張性のあるモニタリングが可能になる可能性が示されています。健常加齢から認知症に至る記憶低下の軌跡を評価する新たな手法となりうる点が臨床的に注目されます。

限界

  • 対象は51名と比較的小規模であり、単一のコホートでの検証にとどまっています。
  • 遠隔・無監督下での実施であるため、実施環境や個人差による影響が結果に含まれている可能性があります。
