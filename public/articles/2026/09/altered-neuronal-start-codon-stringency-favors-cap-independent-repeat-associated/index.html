神経細胞における開始コドン厳格性の変化がキャップ非依存的なリピート関連非AUG翻訳を促進する

Altered neuronal start codon stringency favors cap-independent repeat-associated non-AUG translation.

C9orf72関連ALS/FTDの原因となる異常タンパク質産生機構(RAN翻訳)について、神経細胞では通常と異なる翻訳開始の仕組みが働き、キャップ非依存的な翻訳が優位になることを培養細胞モデルで示した基礎研究です。

背景・目的

C9orf72遺伝子のイントロン領域にあるGGGGCCリピート配列の異常な伸長は、筋萎縮性側索硬化症(ALS)や前頭側頭型認知症(FTD)の原因となります。このリピートは通常の翻訳開始のルールに従わない特殊な翻訳(RAN翻訳)を引き起こし、神経毒性を持つジペプチドリピートタンパク質を作り出すことが知られています。しかし、このRAN翻訳が細胞の種類によってどのように調節されているかは十分に分かっていませんでした。

対象

ヒト由来のiNeurons(誘導神経細胞)およびげっ歯類の神経細胞を用いた培養細胞モデル。CGGリピートおよびGGGGCCリピートという2種類の異なる反復配列を対象に検討されました。

方法

分子生物学的手法を用いて、mRNAの5'キャップ構造への依存性がRAN翻訳の効率にどう影響するかを、神経細胞と他の細胞種で比較しました。またeIF4E阻害薬(キャップ依存的翻訳を止める薬剤)を用いた処理実験や、翻訳開始因子eIF1・eIF5の発現・局在を調べる実験を行いました。

結果

神経細胞(ラット由来神経細胞およびヒトiNeurons)では、他の細胞種と比べてキャップ非依存的なRAN翻訳が優位に生じることが、2種類のリピート配列・複数の読み枠で共通して確認されました。キャップ依存的翻訳を阻害する薬剤を使うと、神経細胞特異的にRAN翻訳がさらに増強されました。また、キャップ非依存的なRAN翻訳は、翻訳開始に必要な開始コドンへの厳密さが低いことが分かり、この現象の背景には神経細胞で開始コドンの厳格性そのものが全体的に緩んでいるという特徴があることが判明しました。これは翻訳開始因子eIF1が細胞質側に偏って分布することと関連しており、eIF5を過剰発現させると開始コドンの厳格性が回復し、逆にキャップ依存的なRAN翻訳が優位になることが示されました。

臨床的示唆

本研究は培養細胞を用いた基礎的な分子メカニズム解明であり、現時点でリハビリテーション支援や患者への直接的な臨床対応に結びつく知見ではありません。ただし、ALS/FTDの病態根幹である異常タンパク質産生の仕組みを神経細胞特異的に説明するものであり、将来的な治療標的探索の基礎情報として位置づけられます。

限界

  • 培養細胞モデルでの検討であり、生体内(in vivo)での現象再現性やヒト患者での妥当性は確認されていません。
  • 臨床症状や機能予後との関連については本研究の範囲外であり、直接的な臨床応用にはさらなる研究が必要です。
