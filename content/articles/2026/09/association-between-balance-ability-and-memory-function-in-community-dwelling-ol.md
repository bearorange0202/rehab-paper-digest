# 地域在住高齢者におけるバランス能力と記憶機能の関連:横断研究

**Original title:** Association between balance ability and memory function in community-dwelling older adults: A cross-sectional study.

## 原著論文

- Original title: Association between balance ability and memory function in community-dwelling older adults: A cross-sectional study.
- 著者: Ohki M, Minehisa K, Sakai K, Takei M, Imaoka M, Takeda M, Nakamura M
- 雑誌名: Medicine
- 公開日: 記載されていません
- 発行日: 2026-09-25
- DOI: 10.1097/MD.0000000000050786
- PMID: 42798118
- 原著論文へのリンク: https://doi.org/10.1097/MD.0000000000050786

## 概要

認知機能が正常な地域在住高齢者49名を対象に、開眼片脚立位時間がACE-IIIの総合得点および記憶領域と有意に関連することを示した横断研究。

## 背景・目的

運動は認知症予防のための非薬物的介入として広く推奨されているが、どの種類の運動機能が認知機能のどの側面と関連するかを明らかにすることが、より適切で効果的な運動選択につながる。本研究は、認知機能と関連しうる運動機能を検討することを目的とした。

## 対象

地域在住の認知機能正常な高齢者49名(平均年齢74.33±6.16歳)。


## 方法

認知機能はAddenbrooke's Cognitive Examination-III(ACE-III)で評価し、運動機能は握力、30秒椅子立ち上がりテスト、歩行速度、開眼片脚立位時間(UPST)により評価した。身体活動量は無線式活動量計で測定した。単変量回帰分析でACE-III総得点と関連する要因を抽出した後、複数のモデルによる重回帰分析を行い、運動機能・身体活動指標とACE-III総得点および記憶領域との関連を検討した。

## 結果

単変量回帰分析では、年齢、骨格筋量指数、UPST、歩数、運動量(METs・h)がACE-III総得点と有意に関連していた。重回帰分析では、複数のモデル(Model1〜4)においてUPSTとACE-III総得点との間に有意な関連が認められた(β=0.337〜0.379、いずれもP<.05)。また、ACE-III記憶領域についても、Model1、2、4においてUPSTとの有意な関連が示された(β=0.301〜0.350、いずれもP<.05)。

## 臨床的示唆

認知機能が正常な高齢者において、良好なバランス能力(片脚立位時間)が良好な認知機能、特に記憶機能と関連していたことから、バランス評価が認知機能の状態を把握する簡便な補助的指標となりうる可能性が示唆される。運動プログラムを検討する際に、バランス能力に着目した評価・介入の意義を考える一助となりうる。

## 限界

- 横断研究デザインであるため、バランス能力と記憶機能の因果関係は明らかにできない。
- 対象者数が49名と少なく、認知機能が正常な地域在住高齢者に限られるため、結果の一般化には注意が必要である。
