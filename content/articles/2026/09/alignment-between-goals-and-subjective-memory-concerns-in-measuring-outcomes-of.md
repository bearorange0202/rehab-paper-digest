# 脳卒中後の記憶リハビリテーションにおける目標と主観的記憶の問題の一致度がアウトカム測定に与える影響

**Original title:** Alignment between goals and subjective memory concerns in measuring outcomes of memory rehabilitation post-stroke.

## 原著論文

- Original title: Alignment between goals and subjective memory concerns in measuring outcomes of memory rehabilitation post-stroke.
- 著者: Kamberis N, Lawson D, Stolwyk RJ, das Nair R, Cadilhac DA, Wong D
- 雑誌名: Disability and rehabilitation
- 公開日: 2026-09-18
- 発行日: 2026-09-18
- DOI: 10.1080/09638288.2026.2724043
- PMID: 42758491
- 原著論文へのリンク: https://doi.org/10.1080/09638288.2026.2724043

## 概要

脳卒中後の記憶リハビリでは、参加者自身が設定した目標に一致する記憶の問題の方が、目標と一致しない問題よりも初期介入で改善しやすいことが示された。

## 背景・目的

脳卒中後の記憶リハビリテーションは記憶の問題を改善しうるが、その効果は測定しにくく、時間とともに変化しうる。本研究は、参加者のリハビリ目標と一致する記憶の問題が、目標と一致しない記憶の問題と比べて介入に対する反応が異なるかを検討し、より的を絞ったアウトカム評価方法の特定を目的とした。

## 対象

Memory-SuSTAIN試験(脳卒中後記憶スキルグループ〈SMSG〉後の維持介入〈ブースターセッション、電子リマインダー、通常ケア〉を評価する試験)内で行われたサブ研究に参加した脳卒中サバイバー38名。


## 方法

自己報告による日常の記憶の失敗(EMQ-R:忘却領域と注意領域)と、記憶関連の目標達成度(Goal Attainment Scaling: GAS)を測定した。参加者が主に挙げた記憶目標の領域と一致する主観的記憶の懸念を「目標一致」、一致しないものを「目標不一致」とした。アウトカムは盲検化された評価者により、SMSG後6週、12週、18週、24週の時点で測定された。

## 結果

SMSG初期介入後、目標一致のEMQ-R領域スコアは有意に改善(平均変化7.68点)した一方、目標不一致のスコアには有意な改善が見られなかった(平均変化3.63点)。その後の維持介入では、目標一致・目標不一致いずれの主観的記憶の懸念も改善した。

## 臨床的示唆

目標との一致度を追跡することで、認知リハビリテーションのアウトカムを標準化された測定にとどまらず、より個別化・的を絞った形で評価できる可能性が示唆される。これは脳卒中後の記憶リハビリテーションの提供方法を最適化する一助となりうる。

## 限界

- 対象者数は38名と小規模なサブ研究であり、結果の一般化には注意が必要
- 特定の介入プログラム(SMSGおよび関連する維持介入)の枠組み内での知見であり、他の記憶リハビリ手法への適用可能性は不明
- 自己報告による主観的評価(EMQ-R)や目標達成度評価(GAS)に基づくため、客観的な記憶機能検査との関係は検討されていない
